# Git Test

一个用于测试 Git 操作的示例项目。

## 项目简介

本仓库用于学习和测试 Git 的基本操作，包括：

- 📦 仓库初始化与克隆
- 📝 文件的添加与提交
- 🔄 分支管理
- 🚀 远程推送与拉取

## 文件结构

| 文件 | 说明 |
|------|------|
| `book.txt` | 主文本文件 |
| `README.md` | 项目说明文档 |

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/bunnygirl-com/git-test.git

# 进入项目目录
cd git-test
```

## Git 常用命令

```bash
# 查看状态
git status

# 添加文件
git add .

# 提交更改
git commit -m "提交说明"

# 推送到远程
git push

# 拉取最新代码
git pull
```
